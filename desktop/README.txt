=====================================================
🦝 Raccon Mail - Official Desktop Edition (v1.0.0)
=====================================================

Thank you for downloading the official Raccon Mail Desktop client!

FEATURES:
• Native desktop window with hardware acceleration
• System Tray integration (quick compose & notifications)
• Local SQLite offline mail caching & instant keyboard (Ctrl+K)
• Zero telemetry, zero third-party tracking

HOW TO LAUNCH:
Option 1: Double-click 'RacconMail-Launcher.bat' to launch immediately.
Option 2: If you have Node.js installed, open terminal in this folder and run:
          npm install && npm start
Option 3: Launch in any browser or PWA mode at https://racconmail.eu/inbox
